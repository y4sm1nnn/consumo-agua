## Sobre o projeto e sua proposta:

Sistema desenvolvido para a campanha de conscientização ambiental municipal,

com o objetivo de classificar o perfil de consumo de água dos imóveis

e emitir alertas educativos aos moradores com base no tipo de imóvel e no

consumo mensal registrado em metros cúbicos.
